# 3D-Druck Rechner

Eine einfache iOS-App zur Berechnung der Kosten eines 3D-Drucks.

## Funktionen

- **Filament-Preis eingeben**: Geben Sie den Preis für eine Rolle Filament ein
- **Gewicht pro Rolle**: Geben Sie das Gewicht einer Filamentrolle in Gramm ein
- **Verbrauchtes Gewicht**: Geben Sie an, wie viel Gramm für den Druck benötigt werden
- **Anzahl Kopien**: Optional können Sie die Anzahl der Kopien angeben (Standard: 1)
- **Automatische Berechnung**: Die App berechnet automatisch die Gesamtkosten

## Voraussetzungen

- iOS 17.0 oder höher
- Xcode 15.0 oder höher
- Swift 5.0

## Installation

1. Öffnen Sie `DreiDDruckRechner.xcodeproj` in Xcode
2. Wählen Sie Ihr Zielgerät oder einen Simulator aus
3. Klicken Sie auf "Run" (⌘R)

## Verwendung

1. Geben Sie den Preis Ihrer Filamentrolle ein
2. Geben Sie das Gesamtgewicht der Rolle in Gramm ein
3. Geben Sie das verbrauchte Gewicht für Ihren Druck ein
4. Optional: Ändern Sie die Anzahl der Kopien
5. Klicken Sie auf "Berechnen"
6. Die Gesamtkosten werden angezeigt

## Beispiel

- Filament-Preis: 25,00 €
- Gewicht pro Rolle: 1000 g
- Verbrauchtes Gewicht: 50 g
- Anzahl Kopien: 2

**Ergebnis**: 2,50 €
